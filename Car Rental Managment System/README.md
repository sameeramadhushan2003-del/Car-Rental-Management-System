# Car Rental Management System 🚗

## 📖 About the Project
A comprehensive, console-based Car Rental Management System developed in C++. This system allows users to manage vehicle rentals, track available cars, and process customer information efficiently. It is built using modular programming principles, separating models, custom data structures, and core logic into distinct header files to maintain a clean and scalable codebase.

## ✨ Features
* **Vehicle Management:** View, organize, and track a fleet of available vehicles.
* **Rental Processing:** Process customer rentals and calculate total rental costs.
* **Custom Data Structures:** Implemented using optimized data structures for efficient memory management.
* **Modular Codebase:** Clean separation of concerns for easier debugging and future updates.
* **Interactive Console UI:** User-friendly command-line interface for easy navigation.

## 📂 Project Structure
* `main.cpp` - The entry point and main execution loop of the application.
* `Models.h` - Contains the core object models and classes (e.g., Car properties, Customer details).
* `DataStructures.h` - Custom-built data structures used to store and manipulate application data.
* `Functions.h` - Handles the core business logic and backend operations.
* `DisplayFunctions.h` - Dedicated functions for rendering menus, tables, and the overall console UI.
* `.vscode/` - Configuration files for building and debugging in Visual Studio Code.

## 🛠️ Built With
* **Language:** C++
* **IDE:** Visual Studio Code
